Frontend news publishing and editorial workflow for WordPress with role-aware dashboards, reporter submissions, moderation, notifications and analytics.

== Description ==

NewsPortal Manager provides a frontend workflow for administrators, reporters and subscribers.

Features include:

* AJAX user registration using WordPress accounts
* Role-aware frontend dashboard
* Reporter news submission form
* Pending/published post workflow
* Frontend post and comment moderation for administrators
* Activity notifications
* Daily visitor and post-view tracking
* Reporter performance statistics
* Shortcode: [my_custom_dashboard]

Authentication uses the standard WordPress user system and WordPress authentication cookies.

== Installation ==

1. Upload the plugin folder to /wp-content/plugins/.
2. Activate NewsPortal Manager through the WordPress Plugins screen.
3. Add [my_custom_dashboard] to the dashboard page.
4. Configure the surrounding site pages/theme for the desired news portal experience.
